# Bugbot rules

## English only

All human-readable text in this repository must be written in English.

Flag any added or changed content that includes non-English words or phrases in:

- User-facing UI copy (labels, buttons, placeholders, error messages, tooltips)
- Documentation and markdown
- Comments and commit-message-style descriptions in code
- PR-visible strings and templates

Do not flag:

- Proper nouns, brand names, package names, or API identifiers
- Code identifiers (variable/function/class names) unless they introduce non-English UI copy
- Technical terms that are standard English loanwords in programming (e.g. "locale", "cache")
- Quoted third-party content that must remain in its original language for correctness

When filing a finding, cite the non-English text and ask for an English replacement.
